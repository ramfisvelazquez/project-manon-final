# RAMMY BEAUTY 💄

Landing page moderna inspirada en el estilo visual de Rare Beauty, desarrollada con Reflex.

## ✨ Descripción

RAMMY BEAUTY es una landing page enfocada en ventas de maquillaje con un diseño elegante, minimalista y moderno.

El proyecto incluye:

- Navbar interactiva
- Hero section
- Sección de productos
- Botones con efectos hover
- Scroll suave entre secciones
- Footer personalizado
- Diseño responsive

---

## 🛠 Tecnologías utilizadas

- Python
- Reflex
- HTML/CSS

---

## 🚀 Instalación

Clona el repositorio:

```bash
git clone https://github.com/ramfisvelazquez/project-manon-final.git
```

Entra a la carpeta:

```bash
cd project-manon-final
```

Instala las dependencias:

```bash
pip install -r requirements.txt
```

Ejecuta el proyecto:

```bash
reflex run
```
